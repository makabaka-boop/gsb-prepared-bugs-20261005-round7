

## 试启动与确认
在 nor-fw 运行 cargo run --bin trial-demo。新增 trial API 使用镜像内独立的两个 NOR 元数据扇区；原发布流程仍可独立运行。trial::install 安装后保留最后确认固件，候选最多交付两次试启动，每次计数在交付前持久化；下一次启动回退。只有本次试启动的固件完整身份和交付令牌才能确认，确认可幂等重放；旧令牌、未启动候选或外来身份不能改变确认版本。等待确认期间拒绝新候选。回退后的下一次更新不能擦掉最后确认槽；版本不得重复使用。镜像重开、任意元数据字节写入或擦除中断仍须能找到有效确认固件，元数据换代保持此性质。旧的原始镜像应使用新布局重新工厂初始化；不自动扩展旧镜像。
